# Design: cleanup-currency-subquery

## Context

В подзапросе `coa_crncy` (поток ЭКС) валюта счёта выбирается через `row_number() OVER (… ORDER BY NULL::text)` — «взять первую строку» без порядка — и пару оконных `min/max` для проверки однозначности (`mx = mn`). Конструкция зафиксирована как кандидат на упрощение в дизайне `add-d-agr-cred-load` (решение 5) и вынесена за рамки `make-load-deterministic`.

## Goals / Non-Goals

**Goals:**

- Явная и детерминированная реализация правила «учитываем только однозначную валюту счёта».
- Убрать оконные `rn/mn/mx` и `ORDER BY NULL::text`.
- Сохранить вывод колонок `agra_l001_crncy_id` / `agra_l007_crncy_id` / `agra_l009_crncy_id` и фолбэк-логику.

**Non-Goals:**

- Изменение соответствий «тип договора → счёт (`AGRA_L…`)».
- Оптимизация производительности (стоимость подзапроса не является проблемой).
- Изменение других подзапросов.

## Decisions

1. **Один уровень агрегации вместо двух.** `GROUP BY (agr_cred_id, meas_cd)` + `HAVING (min(crncy_id) = max(crncy_id))`: если все непустые значения совпадают — берём `min(crncy_id)`; при полностью NULL-группе условие не выполняется — группа отбрасывается (атрибут не заполняется). Далее — прежний пивот `max(CASE …)` по `agr_cred_id`.
2. **Проверка однозначности явная.** `HAVING min = max` читается как «все значения совпадают» и не требует выбора «первой строки» — исчезает зависимость от порядка.
3. **NULL-политика.** Полностью NULL-группа не учитывается (как и раньше); смешанные группы становятся детерминированными (раньше исход зависел от того, какая строка попадёт первой).
4. **Откат** — `git revert` коммита применения.

## Risks / Trade-offs

- [Смешанные NULL-группы, где раньше «иногда везло»] → теперь стабильный фолбэк; поведение зафиксировано сценариями спеки.
- [Скрытая зависимость потребителей от прежней нестабильности] → на песочнице сравнить срез до/после.

## Migration Plan

Один коммит: правка подзапроса. Проверка в песочнице: сравнить значения `agra_l00x_crncy_id` до/после на рабочем объёме (ожидаемо: без изменений, кроме ранее нестабильных кейсов).
